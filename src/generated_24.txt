
## API Endpoints

### Authentication
- `POST /api/v1/auth/register` - Register a new user

### Tasks
- `POST /api/v1/tasks` - Create a new task (manual entry)
- `POST /api/v1/tasks/voice` - Create a task from voice input
- `POST /api/v1/teams/{team_id}/tasks` - Create a task within a team
