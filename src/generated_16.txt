
## Database Schema

The application uses SQLAlchemy ORM to define the following models:

### Users
- id (PK)
- first_name
- last_name
- email (unique)
- password
- created_at
- updated_at

### Tasks
- id (PK)
- user_id (FK to users)
- title
- description
- due_date
- priority
- category
- completed
- created_at
- updated_at

### Categories
- id (PK)
- name
- created_at
- updated_at
